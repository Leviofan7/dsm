# Отчёт о проделанной работе: Папка как живое окружение

Мы успешно завершили рефакторинг работы с локальными директориями в приложении Data Sources Management. Теперь локальные папки больше не загружаются в векторную базу данных Chroma, а работают как **живое файловое окружение**, что обеспечивает мгновенную загрузку UI, отсутствие зависаний и высокую актуальность контекста.

## 🛠️ Основные изменения

1. **Мгновенное подключение (Quick Fix):**
   - Убраны блокирующие вызовы `auto_reindex_if_needed`, которые вызывали зависание чата (UI).
   - Теперь подключение локальной папки происходит мгновенно со статусом `ready`.

2. **Двухуровневый движок контекста (Adaptive Engine):**
   - Разработан `folder_service.py`, который динамически оценивает размер папки в токенах.
   - **Режим ⚡ Direct Snapshot:** Если объём файлов в папке < 15 000 токенов, всё содержимое файлов передаётся LLM напрямую.
   - **Режим 🛠️ Workspace:** Если объём превышает 15 000 токенов, LLM передаётся дерево папок и топ-50 последних изменённых файлов (манифест).

3. **Инструменты файловой системы для Агента (FS Tools):**
   - Создан отдельный сервер MCP `fs_tools.py` для обеспечения доступа к файлам в режиме Workspace.
   - Агенту предоставлены новые инструменты: `read_file` (чтение по требованию), `outline_file` (анализ структуры/импортов), `search_files` (поиск по содержимому текстовых файлов).
   - Сервер зарегистрирован в `mcp_manager` и готов к использованию агентами.

4. **Обновления интерфейса (UI):**
   - В модальном окне подключения локальной папки добавлено мгновенное превью структуры.
   - Теперь UI оценивает объём в токенах и отображает бейдж режима (⚡ Direct Snapshot или 🛠️ Workspace Mode).
   - Убрана кнопка "Переиндексировать" для локальных папок, так как теперь чтение происходит в реальном времени.

5. **Оптимизация Anthropic Cache Control:**
   - Для моделей Anthropic внедрена поддержка `cache_control: "ephemeral"` на системном промпте, содержащем контекст папки, что существенно ускоряет ответы при повторных запросах к одним и тем же файлам.
