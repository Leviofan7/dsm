# Архитектура и Логика работы агента Contextus

Давайте разложим по полочкам, как мы построили эту систему, почему она работает именно так, и какую роль во всем этом играет Claude Code.

## 1. Кто есть кто? (Contextus vs Claude Code)

У вас сейчас работают **ДВЕ абсолютно разные** ИИ-системы, которые не пересекаются в своих задачах:

1. **Contextus (Веб-интерфейс)** — это ваш **Агент-исследователь**. Он живет в браузере. Его задача — ходить по интернету, искать информацию, анализировать базы данных, парсить крипту и сохранять результаты в виде отчетов.
2. **Claude Code (Терминал)** — это ваш **Агент-программист**. Он живет в черном терминале. Его задача — писать код для самого проекта (React, Python, Docker). 

**Ответ на ваш вопрос:** Нет, Contextus *не использует* Claude Code для записи файлов. Claude Code — это отдельная программа. Когда Contextus хочет сохранить файл, он использует свой собственный встроенный инструмент `write_file` (из MCP-сервера `workspace`).

## 2. Как модель понимает, что ей делать? (Логика Contextus)

Когда вы пишете запрос в интерфейс (например: *"Зайди на Immunefi и сохрани отчет"*), запрос проходит через сложный конвейер, который мы с вами построили:

### Шаг 1: Doorman (Швейцар / Маршрутизатор)
Запрос попадает в `LLMManager`, где его встречает функция **Doorman** (`route_intent`).
- Doorman анализирует текст запроса и решает, что это за задача.
- Он видит слова "зайди", "сохрани", "браузер" и классифицирует задачу как `research` или `browser_automation`.
- Затем Doorman смотрит в файл `models.yaml` и видит: *"Ага, для задач research у нас жестко закреплена локальная модель `gemma4-26b`"*. Он передает ей задачу.

### Шаг 2: Системный промпт (Инструкция)
Модели `gemma4-26b` выдается огромный "системный промпт" (мы его только что переписали). Там написано:
- "У тебя есть инструменты: браузер, работа с файлами".
- "Вот список прикрепленных папок, сохраняй только туда".
- "Запрещено врать. Если ничего не скачал, так и скажи".

### Шаг 3: Планировщик (Учебный режим)
Так как локальная модель (Gemma) не такая умная как GPT-4, мы сделали ей костыль — **Планировщик**.
- Мы просим её: *"Сначала напиши план текстом, не трогай инструменты"*.
- Модель пишет: *"1. Вызвать `goto_url`. 2. Вызвать `write_file`"*.
- Этот план сохраняется в памяти как руководство к действию. Это резко снижает шанс того, что модель "забудет", что от нее хотели.

### Шаг 4: Цикл выполнения (Tool Calling)
Модель начинает выполнять свой же план:
1. Она шлет JSON-запрос: `{"name": "goto_url", "arguments": {"url": "https://immunefi.com"}}`.
2. Бэкенд перехватывает это, отправляет команду в **MCP-сервер `web-stealth`**. Тот реально открывает браузер, копирует текст страницы и возвращает его модели.
3. Модель получает текст. По плану ей нужно сохранить его. Она генерирует второй JSON: `{"name": "write_file", "arguments": {"relative_path": ".../security_scan.txt", "content": "..."}}`.
4. Бэкенд отправляет это в **MCP-сервер `workspace`**. Тот физически создает файл на жестком диске.

### Шаг 5: Пост-верификация (Анти-враньё)
Когда модель говорит *"Я всё сделала, файл сохранен"*, наш код проверяет:
- *"А ты реально вызывала инструмент `write_file`?"*
- Если да — отдаем ответ вам в чат.
- Если нет (решила соврать) — мы перехватываем ответ и пишем вам: *"Системная коррекция: модель соврала, вот текст, который она скачала, но файл не создан"*.

## 3. Зачем тогда мы настраивали Claude Code?

Мы настраивали `claude_settings.py` (через LiteLLM) исключительно для того, чтобы когда вы сидите в консоли и просите: *"Claude, поправь мне CSS"*, Claude Code не тратил ваши платные токены в облаке Anthropic, а перенаправлял запрос на ту же самую локальную бесплатную `gemma4-26b` (или Gemini) в зависимости от сложности задачи.

## Итог
* **Кто ищет инфу в браузере?** Бэкенд Contextus (через Python-код `web-stealth`)
* **Кто пишет файлы отчетов?** Бэкенд Contextus (через Python-код `workspace`)
* **Какой ИИ этим управляет?** `gemma4-26b` (через Ollama), управляемая файлом `llm_manager.py`
* **Где Claude Code?** Он сидит в терминале и ждет, пока вы не попросите его написать код проекта. К браузерному агенту он отношения не имеет.
